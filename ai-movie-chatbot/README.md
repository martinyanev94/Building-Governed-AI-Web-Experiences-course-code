# Conversational Movie Recommendation Chatbot

This lesson connects dialogue state to a transparent recommendation service and a grounded response template.

Run the example from the project directory:

```bash
cd ai-movie-chatbot
python -m src.main
```

Expected output:

```text
Try Game Night. It matches comedy and it isn't in your watched list.
```

Run the tests:

```bash
cd ai-movie-chatbot
python -m pytest
```
